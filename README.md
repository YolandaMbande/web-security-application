# Web Security Application

A Java enterprise web application created as part of learning web application development and security concepts.

## About

This project is an employee-based web application developed using Java Enterprise technologies.

The application is separated into a web application module and an Enterprise JavaBeans (EJB) module, demonstrating a multi-layered approach to building Java web applications.

The project was created while exploring enterprise application development and web security concepts.

## Technologies

- Java
- Java EE / Jakarta EE concepts
- Enterprise JavaBeans (EJB)
- Web technologies
- HTML

## Project Structure

### `EmployeeWebApplication`

Contains the web-facing components of the application responsible for handling the application's user interface and web functionality.

### `EmployeesEJBModule`

Contains the Enterprise JavaBeans components used to separate application and business logic from the web layer.

## Concepts Practiced

This project provided practice with:

- Java enterprise web development
- Enterprise JavaBeans
- Separation of application layers
- Web application structure
- Server-side application development
- Web security concepts

## Purpose

This is an academic/learning project created while developing an understanding of Java enterprise applications and web security.
